# STUDENT-EXPENSE-MANAGER
A PYTHON PROGRAM MADE TO REGULATE AND HAVE TRACK FOR EXPENSES DONE BY A STUDENT.
The program stores the user's expenses in a for the file expenses.txt. 
Each expense includes the following categories: amount, category (food, travel, study, other), some note, and date and time. 
The user can then view a summary which shows total expenditure and expenditure by category, which again includes a simpler ASCII bar chart.
